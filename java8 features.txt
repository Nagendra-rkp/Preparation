One-Line Interview Answer

filter() is used for filtering records based on a condition, whereas map() is used for transforming one object into another object or value.

filter = Select Data
.filter(emp -> emp.getSalary() > 50000)
✅ Keeps matching records

map = Convert Data

.map(Employee::getName)
✅ Converts one form to another

Map vs FlatMap

Map

Returns one value for one input.

List<String> names =
Arrays.asList("Nagendra","Rahul");

names.stream()
     .map(String::toUpperCase)
     .forEach(System.out::println);
	 
Why flatMap()?

Suppose you have:

List<List<String>> list =
 Arrays.asList(
   Arrays.asList("Java","Spring"),
   Arrays.asList("Kafka","Docker")
 );
 Data looks like:
 [
 [Java, Spring],
 [Kafka, Docker]
]
This is a List of Lists.

Using map()

list.stream()
    .map(x -> x)
    .forEach(System.out::println);
	
	Output:
	[Java, Spring]
[Kafka, Docker]

Using flatMap()

list.stream()
    .flatMap(Collection::stream)
    .forEach(System.out::println);
Output:	
	Java
Spring
Kafka
Docker

map() is used when one input element produces one output element. flatMap() is used when one input element produces multiple output elements or when dealing with nested collections. flatMap() flattens multiple streams into a single stream. For example, converting List<List<String>> into List<String> is a common use case of flatMap().

map() converts one object into one object, whereas flatMap() converts one object into multiple objects and then flattens them into a single stream. For example, converting List<List<String>> into List<String> is a common use case of flatMap().

filter()  ---> Predicate ---> test() ---> true/false
